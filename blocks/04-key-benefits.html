04 · Key benefitsStrongly recommended

Scannable reasons to choose the product, each led by an image. The block is called ‘Key benefits’ internally, but its heading is a free, editable field.

Example content is realistic but placeholder (Danfoss Turbocor TTH/TGH). Specs and claims are not verified. Bracketed ‘Image’ boxes stand for photography.

Content fields

FieldReq.Notes
HeadingRFree text, no fixed default. Write something specific, e.g. ‘Why choose oil-free compression’
Intro textO
Benefit ×3–6RImage 3:2 (alt required) + title ≤ 40 + description ≤ 140; optional link

Variants

  • Image cards (default)
  • Large image cards — 2 across at desktop; for 2–4 benefits.

Responsive behaviour

Mobile1 across
Tablet2 across
Desktop / Wide3 across (Large variant: 2 across)

Editor / design guidance

  • Never more than 6. If there are more, move detail to Rich content.
  • Images should show the benefit (a detail, a diagram, a site), not generic stock.

Source of truth: docs/block-library.md, docs/design-logic.md. R = required, O = optional.

Wireframes

Frames are scaled for review; layout is computed at true device width (1440 / 820 / 390). Wide ≥1600 uses the Desktop layout with a capped 1360px container.

Why choose oil-free compression

Magnetic-bearing technology changes what a compressor can do for your plant. (Heading and intro are both editable.)

Benefit image · 3:2

Oil-free operation

Magnetic bearings remove the oil system, so there is no oil to manage or lose to the heat exchangers.

Benefit image · 3:2

Variable-speed efficiency

Integrated drive matches output to load, with strong part-load performance.

Benefit image · 3:2

Quiet running

Low vibration and sound levels suit noise-sensitive sites.

Benefit image · 3:2

Compact footprint

Lighter and smaller than comparable screw or scroll solutions.

Benefit image · 3:2

Low maintenance

Fewer wearing parts and no oil changes cut service time and cost.

Benefit image · 3:2

Soft start

Low inrush current reduces demands on site electrics.

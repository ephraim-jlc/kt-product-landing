03 · Contact / CTA bandRequired · last

Final nudge before the footer. The footer form stays as the global fallback; this band makes the ask explicit and gives the Product selector a home.

Example content is realistic but placeholder (Danfoss Turbocor TTH/TGH). Specs and claims are not verified. Bracketed ‘Image’ boxes stand for photography.

Variants

  • CPD
  • Product selector — Links to the external stock / compare / quote tool.

Responsive behaviour

MobileStacked, full-width buttons
TabletStacked, buttons side by side
Desktop / WideTwo columns: message + CTAs left, contact details right

Editor / design guidance

  • Lime-green full-bleed band; white buttons for contrast on green (to be checked for accessibility).
  • Choose the variant by page goal; default is Contact.

Source of truth: docs/block-library.md, docs/design-logic.md. R = required, O = optional.

Frames are scaled for review; layout is computed at true device width (1440 / 820 / 390). Wide ≥1600 uses the Desktop layout with a capped 1360px container.

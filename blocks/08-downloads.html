08 · DownloadsOptional

Datasheets, brochures, manuals and CPD material in one place, instead of inline links.

Example content is realistic but placeholder (Danfoss Turbocor TTH/TGH). Specs and claims are not verified. Bracketed ‘Image’ boxes stand for photography.

Content fields

FieldReq.Notes
TitleRDescriptive, not a file name
File / linkR
File type + sizeautoBadge generated
DescriptionO
Gated?ORoutes to a form first

Variants

  • List (default)
  • Cards — With cover thumbnails.

Responsive behaviour

MobileSingle column list
TabletSingle column list / 2 cards
Desktop / Wide2-column list or 4 cards

Editor / design guidance

  • CPD items get a green badge and ‘Request’ action to reinforce the Request a CPD CTA.

Source of truth: docs/block-library.md, docs/design-logic.md. R = required, O = optional.

Wireframes

Frames are scaled for review; layout is computed at true device width (1440 / 820 / 390). Wide ≥1600 uses the Desktop layout with a capped 1360px container.

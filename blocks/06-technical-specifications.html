06 · Technical specificationsRequired if specs exist

Generates a table from structured data. Editors key the data in, so authoring needs to be fast and consistent.

Example content is realistic but placeholder (Danfoss Turbocor TTH/TGH). Specs and claims are not verified. Bracketed ‘Image’ boxes stand for photography.

Content fields

FieldReq.Notes
Block titleR
Spec groupsRGroup label → rows of Parameter / Value / Unit
FootnoteOConditions, tolerances, test standard
Datasheet linkO
Authoring aids–Repeater rows, paste-from-spreadsheet/CSV, reusable group presets, live preview

Variants

  • Single table
  • Grouped (default) — Collapsible groups.
  • Model matrix — Columns = models.

Responsive behaviour

MobileTable scrolls horizontally; first column sticky
TabletFull table
Desktop / WideFull table; zebra rows; blue header

Editor / design guidance

  • Never build tables inside Rich content.
  • Keep units in their own column so values stay scannable.
  • Matrix variant is for within-range reference only; model comparison belongs to the Product selector (Comparison block was dropped).

Source of truth: docs/block-library.md, docs/design-logic.md. R = required, O = optional.

Frames are scaled for review; layout is computed at true device width (1440 / 820 / 390). Wide ≥1600 uses the Desktop layout with a capped 1360px container.
